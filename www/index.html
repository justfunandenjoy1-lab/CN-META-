AI Provider Settings

Enabled providers are tried top to bottom. If all keys/models of one provider fail, the next provider is used. Only when everything fails is the item marked "failed".

How to use

  1. Tap "AI providers" and add an API key for at least one provider (Gemini / OpenRouter / OpenAI / Custom).
  2. Add more providers or multiple keys per provider — if one fails, the next is tried automatically.
  3. Choose a platform, then adjust title/keyword settings.
  4. Add images/videos by drag & drop onto the box, by clicking the box, or by "Batch select files".
  5. Use the checkbox on each thumbnail to select items, Shift+click for a range, or tick "Select all".
  6. Press "Generate metadata". Edit titles/keywords yourself afterwards.
  7. For a failed item, press "Regenerate". Use "Regenerate selected" to redo many at once.
  8. Export with "Download CSV" or "Embedded images (ZIP)". On Android, the system Share Sheet will open — choose "Files" or "Downloads" to save, or share to any app.
  • Google Gemini: free key from aistudio.google.com/apikey.
  • OpenRouter: openrouter.ai/keys — many free vision models.
  • OpenAI: platform.openai.com/api-keys.
  • Custom: any OpenAI-compatible endpoint (Groq, Together, DeepSeek, LM Studio, etc.).
  • Embedding writes title, description and keywords inside the JPEG as IPTC and XMP. PNG/WEBP are converted to JPG during embedding.
